**Скачивайте видео и аудио с YouTube и других сайтов с лёгкостью!**

[🇬🇧 Read in English](README.md)

## ✨ Возможности

- 🎥 Скачивание видео в различных качествах (Лучшее, 1080p, 720p, 480p, 360p)
- 🎵 Извлечение аудио из видео
- 🌐 Поддержка нескольких языков (Английский/Русский)
- 🚀 Быстрая загрузка с помощью yt-dlp
- 📦 Автоматическая установка FFmpeg
- 🖥️ Современный тёмный интерфейс с перетаскиваемой заголовочной панелью

## 📋 Требования

- Python 3.8 или выше
- PyQt6
- yt-dlp

## 🚀 Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/mvita267-228/YouWizard.git
cd YouWizard
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите приложение:
```bash
python main.py
```

## 📁 Структура проекта

```
YouWizard/
├── main.py          # Точка входа приложения
├── ui.py            # Компоненты пользовательского интерфейса

├── LICENSE          # Лицензия GPL-3.0
└── README.md        # Этот файл
```

## 🛠️ Использование

1. Запустите приложение
2. Выберите предпочитаемый язык при первом запуске
3. Вставьте URL видео
4. Выберите качество и формат (Видео/Аудио)
5. Нажмите "Скачать" и дождитесь завершения
