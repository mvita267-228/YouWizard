**Download videos and audio from YouTube and other sites with ease!**

[🇷🇺 Read in Russian](README_RU.md)

## ✨ Features

- 🎥 Download video in various qualities (Best, 1080p, 720p, 480p, 360p)
- 🎵 Extract audio from videos
- 🌐 Support for multiple languages (English/Russian)
- 🚀 Fast downloads with yt-dlp
- 📦 Automatic installation of FFmpeg
- 🖥️ Modern dark-themed interface with draggable title bar

## 📋 Requirements

- Python 3.8 or higher
- PyQt6
- yt-dlp

## 🚀 Installation

1. Clone the repository:
```bash
git clone https://github.com/mvita267-228/YouWizard.git
cd YouWizard
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the application:
```bash
python main.py
```

## 📁 Project Structure

```
YouWizard/

```

## 🛠️ Usage

1. Launch the application
2. Select your preferred language on first run
3. Paste the video URL
4. Choose quality and format (Video/Audio)
5. Click "Download" and wait for completion
