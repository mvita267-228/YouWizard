## 🇬🇧 English Version

### 🚀 About
**YouWizard** is a powerful Python utility for downloading video and audio locally from YouTube and dozens of other popular social networks and video hosting platforms. Fast, simple, and without unnecessary magic — just working tools.

![Screenshot](https://github.com/user-attachments/assets/4a709b06-881a-4b6d-a036-ad24c7145429)

### ✨ Features
- 🎥 **Video & Audio Download**: Support for YouTube and 1000+ other sites via yt-dlp
- 🌐 **Multi-language Interface**: Choose between English and Russian at first launch
- 📹 **Quality Selection**: Pick your preferred quality (Best, 1080p, 720p, 480p, 360p)
- 🛠️ **Auto-Installation**: Automatically downloads full FFmpeg and yt-dlp on first run
- 🎨 **Modern Dark UI**: Sleek dark theme with draggable custom title bar
- 📦 **Modular Architecture**: Clean code structure separated into `main.py`, `ui.py`, and `logic.py`

### 🚀 Quick Start
1. Clone the repository:
   ```bash
   git clone https://github.com/mvita267-228/YouWizard.git
   cd YouWizard
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:
   ```bash
   python main.py
   ```

### 📋 Requirements
- Python 3.8 or higher
- PyQt5
- yt-dlp (auto-downloaded)
- FFmpeg (auto-downloaded, full version)

## 🇷🇺 Русская версия

### 🚀 О проекте
**YouWizard** — это мощная утилита на Python для скачивания видео и аудио локально с YouTube и десятков других популярных соцсетей и видеохостингов. Быстро, просто и без лишней магии — только рабочие инструменты.

- 🎥 **Загрузка видео и аудио**: Поддержка YouTube и 1000+ других сайтов через yt-dlp
